# galax.actionangle

Action-angle coordinates for [galax](https://github.com/GalacticDynamics/galax).

This distribution contributes the `galax.actionangle` portion of the `galax`
namespace package. It depends on `galax.coordinates` and `galax.potential`, and
uses `galax.dynamics` only in its tests and doctests.

```bash
pip install galax.actionangle
```

See the [galax documentation](https://galax.readthedocs.io) for usage.
