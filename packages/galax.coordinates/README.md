# galax.coordinates

Coordinate and phase-space types for
[galax](https://github.com/GalacticDynamics/galax): phase-space positions and
coordinates, their operators, and the frames they live in.

This is the root of galax's import graph — it depends on no other galax
distribution, so it can be used on its own:

```sh
pip install galax.coordinates
```

Installed by default with `galax`.
