# galax.dynamics

Orbit integration and stellar dynamics for
[galax](https://github.com/GalacticDynamics/galax).

This distribution contributes the `galax.dynamics` portion of the `galax`
namespace package. It depends on `galax.coordinates` and `galax.potential`.

```bash
pip install galax.dynamics
```

See the [galax documentation](https://galax.readthedocs.io) for usage.
