# galax.interop.gala

[Gala](https://github.com/adrn/gala) interoperability for
[galax](https://github.com/GalacticDynamics/galax): conversions between gala's
potential and coordinate classes and galax's equivalents.

Registers itself through entry points, so importing it by hand is never needed.

```sh
pip install "galax[interop-gala]"   # or: pip install galax.interop.gala
```
