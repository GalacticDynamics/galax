# galax.interop.galpy

[Galpy](https://github.com/jobovy/galpy) interoperability for
[galax](https://github.com/GalacticDynamics/galax): conversions between galpy's
potential classes and galax's equivalents.

Registers itself through entry points, so importing it by hand is never needed.

```sh
pip install "galax[interop-galpy]"   # or: pip install galax.interop.galpy
```
