# galax.interop.matplotlib

Matplotlib plotting backend for
[galax](https://github.com/GalacticDynamics/galax): `Orbit.plot`, potential
contour plots, and the other visualisation entry points.

Registers itself through entry points, so importing it by hand is never needed.

```sh
pip install "galax[plot-matplotlib]"   # or: pip install galax.interop.matplotlib
```
