# galax.nbody

N-body dynamics for [galax](https://github.com/GalacticDynamics/galax).

This distribution contributes the `galax.nbody` portion of the `galax` namespace
package. It depends on the `galax.orbits` and `galax.potential` portions.

```bash
pip install galax.nbody
```

See the [galax documentation](https://galax.readthedocs.io) for usage.
