# galax.orbits

Orbits and orbit integration for
[galax](https://github.com/GalacticDynamics/galax).

This distribution contributes the `galax.orbits` portion of the `galax`
namespace package. It depends on the `galax.fields`, `galax.coordinates` and
`galax.potential` portions.

```bash
pip install galax.orbits
```

See the [galax documentation](https://galax.readthedocs.io) for usage.
