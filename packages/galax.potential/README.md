# galax.potential

Gravitational potentials for [galax](https://github.com/GalacticDynamics/galax).

This distribution contributes the `galax.potential` portion of the `galax`
namespace package. It depends on `galax.coordinates` and nothing else from
galax.

```bash
pip install galax.potential
```

See the [galax documentation](https://galax.readthedocs.io) for usage.
