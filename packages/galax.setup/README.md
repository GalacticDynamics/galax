# galax.setup

Shared package setup helpers for
[galax](https://github.com/GalacticDynamics/galax).

This distribution contributes the `galax.setup` portion of the `galax` namespace
package: the jaxtyping import hook and the interop entry-point loader that the
other galax portions share. It depends on no other galax portion.

```bash
pip install galax.setup
```

See the [galax documentation](https://galax.readthedocs.io) for usage.
